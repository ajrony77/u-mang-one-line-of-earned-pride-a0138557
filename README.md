# One Line of Earned Pride

A program that writes one line of quiet, earned pride to `/output/entry.txt`:
an apprentice baker, three ruined batches behind him, whose loaf the old
baker tastes, nods at, and sets in the window.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (142 characters, inside the 1–240 gate).
